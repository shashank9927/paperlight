Independent validation uses pypdf 6.10.0 and Poppler 26.07.0 on this machine, with PDF.js as an additional parser. Every downloaded PDF and each PDF inside split ZIPs is checked with pypdf; unencrypted outputs receive a Poppler render. Selected tests inspect geometry, annotations, forms, encryption and pixels. PNG/JPEG ZIPs are independently decoded with the native canvas library. Poppler `pdftotext` was not available in the bundled Windows tools; text comparison uses pypdf and PDF.js.

## Additional release regressions

The complete release matrix runs against the actual Nginx image in Linux with Poppler 22.12.0, Python 3.11.2 and OpenSSL 3.0.22. Chromium, Firefox and WebKit must expose the required worker APIs; release verification does not skip unsupported raster cases.

- `resources.test.ts`: bounded decompression before allocation, nested objects, hostile xref/object counts, cyclic/dishonest page trees, oversized strings/names/numbers, oversized embedded images and exact 500/501-page boundaries. Valid compressed objects and Unicode metadata remain readable.
- `resources.spec.ts`: admission rejection and recovery, 500-page preview-pool bounds and complete rotation, valid exactly-100-MiB processing, and forced worker deadline with retained settings.
- `encrypted-admission.test.ts`: actual bundled QPDF encrypted-probe behavior, wrong credentials, successful retry and unencrypted detection.
- `signatures.test.ts` and `signature-fixture.py`: a real detached CMS signature is valid before processing and independently fails OpenSSL integrity verification after a rewrite. This tests the warning, not certificate trust or certification.
- `compression.spec.ts`: both compression modes on generated text-heavy, scanned, mixed-image and already-optimized fixtures; page dimensions, text, actual sizes and exact-original fallback. JSON records actual results without a quality or savings claim.
- WebP RIFF magic uses byte offsets; binary length bytes cannot shift the marker through UTF-8 decoding. UI password confirmation supports the full 127-byte boundary.
- `scripts/check-hosting.mjs`: real Nginx serves all 13 application routes, restrictive headers, correct script/module-worker/WASM types and 404s for absent assets. Browser tests assert no CSP violations, including font loading. Full browser testing targets this host with `PAPERLIGHT_TEST_ORIGIN`.

## Scope beyond this release's verification

Physical macOS Safari, iOS Safari and Android hardware, pinch zoom, low-memory phone profiling, and a representative external real-world document corpus are unavailable. Automated mobile viewports do not replace devices. Hosted GitHub Actions is configured; local Linux execution verifies the commands, not the remote service. No public deployment was requested.

PDF/A and PDF/UA certification, XFA editing, trusted certificate signatures, and complex document assembly are outside the supported product scope. Unsupported assembly structures are detected and rejected explicitly. Passing synthetic fixtures does not establish compatibility with every PDF producer. See the support matrix for the exact preservation claims.
